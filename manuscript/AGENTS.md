# Manuscript writing

Before drafting or revising manuscript prose in this directory, read `WRITING_STYLE.md` and the latest manuscript refinement handoff. The style guide is an author-review draft; explicit author feedback takes precedence.

The authoritative manuscript is the current Google Doc identified in the handoff. Local snapshots may be older. Do not silently replace its content with a local version.

When preparing prose for chat or Google Docs as part of this manuscript workflow, apply the same read-first rule. Preserve unknown scientific details as placeholders and do not treat stylistic examples as evidence for this project's findings.
