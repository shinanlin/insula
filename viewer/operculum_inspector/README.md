# Operculum native MRI inspector

Independent anatomical review of all reconstructed real contacts on the
shanks already displayed in the operculum supplementary examples. The
six participants use the same verified individual reconstruction as the
companion figures, including D0057 -> D57_2. Selected virtual bipolar
midpoints are separately identified; no point is snapped to a surface.

Build via `scripts/slurm/operculum_review.sbatch export`. The complete
offline file is `results/supplementary/operculum/viewer/operculum-inspector.html`.
It embeds the installed Plotly distribution, exact native MRI voxel values,
Destrieux segmentation, original pial mesh and verified coordinates. Open
the file in a current browser; no server or external resources are required.

## Open on your own computer

The HTTP server runs on a DCC compute node. Its `localhost:8793` address
does not refer to your laptop; opening that URL on your laptop requires
an SSH tunnel. A simpler option is the complete offline HTML (about 98 MiB).
Run this command in a terminal **on your own computer**, not a DCC terminal:

```bash
scp ns458@dcc-login.oit.duke.edu:/cwork/ns458/insula-paper/results/supplementary/operculum/viewer/operculum-inspector.html .
```

Then open the downloaded `operculum-inspector.html` in Chrome or Edge.
It contains all six subjects, native MRI, the 3D contacts and HGA, and needs
no running DCC server after download. Do not download `web/index.html` alone:
that smaller version needs its companion JSON and JavaScript files.

For live access, read `results/supplementary/operculum/viewer/server.json`
for the current compute-node hostname. With the server bound to remote
loopback, use a jump connection from your own computer:

```bash
ssh -N -o ExitOnForwardFailure=yes -L 8793:127.0.0.1:8793 -J ns458@dcc-login.oit.duke.edu ns458@<compute-node-hostname>
```

Keep that terminal open, then visit `http://localhost:8793/`. A forward
through the login node straight to `<compute-node-hostname>:8793` cannot
reach this loopback-only server.

## Anatomical and HGA review

The **D0079 典型案例：LAI7–8 / LFMI2–3** button opens the user's confirmed
illustrative pair. Purple denotes LAI7–8 (user-localized AIC), blue denotes
LFMI2–3 (user-localized operculum). The two existing native HGA curves share
each phase axis; clicking either case button moves the MRI crosshairs to
that exact midpoint. All four physical contacts remain on their original
shanks. The case panel retains the original atlas labels explicitly:
LAI7–8 is superior circular insular sulcus and LFMI2–3 is cerebral white
matter. These manual designations do not overwrite the atlas or the old
automatically selected LFMI7–8 control. Exit the case to return to the
single-electrode display. Case definitions live in `cases.json`.

Its separate before/after orthogonalization and physical-shank/MRI figures
are generated by `vizpub/supplementary/operculum_D0079_case.ipynb`, using
the original approved operation and plotting code. Original native signal
results are under `results/supplementary/operculum/manual_cases/`, outside
the automatically selected control cohort and summaries.

Click a 3D contact or its name to move all three native MRI crosshairs.
Select a recorded bipolar midpoint (in 3D or the bipolar-site menu) to
highlight its two exact contacts and display Stimulus/Delay/Response HGA.
The task menu uses full task names. These are existing Repeat+sound
single-electrode trial means in z score, without a newly introduced SEM
or significance analysis. Native bad channels stay unavailable. All recorded
bipoles on the selected shafts are included irrespective of atlas membership;
each must match the same LEPTO reconstruction before entering the viewer.
Native zscore caches are preferred; the exact saved pre-orthogonalization
branch is available as a documented fallback for an existing analyzed site.
Input paths/hashes and phase availability are saved in per-subject HGA receipts.
The three slices use the exact conformed MRI voxel geometry, with native
tkRAS -> voxel mapping checked during export. Atlas overlay is off by
default for contact labels and the frontal operculum. The separate
"高亮岛叶结构" control is on by default: the existing individual Destrieux
insula mask is purple on all three MRI planes and the matching original
insula surface is purple in 3D. Turn off both controls for plain MRI.
The highlight does not reclassify contacts. MRI contacts are visible only within half a voxel of a slice,
unlike the explicitly labeled +/-4-mm projection used in the static
Figure 1-style illustration. Sliders allow neighboring slices to be inspected.

Manual judgments/notes are stored in the browser and exported as CSV on
request. They include original coordinates, raw atlas label and MRI hash.
They never overwrite analysis metadata, add a pair, or alter the main
cohort. Existing anatomical review flags remain visible. Gray contacts
and Unknown labels remain available for inspection.
