## 五张图的方法链

| 图 | 主要输入 → 分析 → 输出 | 统计/观测单位 |
|---|---|---|
| 1 | 解剖分区、坐标及 HGA 显著性 → 覆盖图、ROI 饼图、响应电极比例 | 去重后的双极通道；跨任务取并集 |
| 2 | Repeat/sound 的试次平均 HGA → 四阶段拼接 → NMF → 功能群、波形、解剖分布 | 每行一个电极；显示波形可能仍含 electrode×task 多行 |
| 3 | 条件别单试次 HGA → 窗内 Mean/P75 → 条件对比；另绘跨任务平均曲线 | 单电极内试次置换；群内检验以电极配对 |
| 4 | pooled 单试次 HGA → 固定窗 SVM / 滑窗 LDA / 跨条件 LDA | 跨被试特征的伪总体试次；部分分支按词分组 CV |
| 5 | 每被试、每电极的单试次 HGA → Ridge 预测 log(RT) → 簇校正与描述性振幅关联 | 被试×任务×电极；功能群仅用于事后分组 |

### 数据层级必须保留

建议所有迁移项目明确区分 `subject → task → recording → trial/item → channel → time`。`channel` 必须包含被试前缀，否则跨被试的同名触点会被误合并。`trial_id` 是一次呈现，`item_id` 是可以重复呈现的词/概念；两者不能互换。

本项目中：PS = PhonemeSequence；LD = LexicalDelay；LND = LexicalNoDelay（BIDS 数据集名称含 LexicalDecRepNoDelay）；PN = PictureNaming；Sentence = SentenceRep。不同分支纳入的任务不同，详见模块。

## 如何理解“参数已核实”

- **结果证据**：已保存 H5 的属性、数组维度或小型 CSV/JSON 直接证明该结果的值。优先级最高，但文件可能没有记录全部参数。
- **实现证据**：当前源码、Slurm/worker 参数与本次检查的依赖实现。可以精确定义当前算法，但单独不能证明历史运行时完全相同。
- **缓存证据**：Notebook 已保存的文本输出。某些路径失效或结果版本改变时，只能称为当时的输出，不能当成当前重新运行的结果。
- **迁移建议**：为新项目提出的规范。没有把建议冒充本项目已经实施的操作。

此次是方法审计与文档整理，未重跑预处理、NMF、置换、decoding 或 RT 模型。也未修改原 Notebook、分析源码、标签或结果。

## 必须随方法一起交接的差异

1. **NMF 当前标签与已拟合权重有 6 个电极不一致。** 当前标签计数为 sensory 39、sustain 80、motor 136；按保存权重/旧 PCA 标签为 39、74、142。现有 functional decoding 输入还记录着旧 assignment 哈希。迁移时要冻结标签版本，并显式保存任何覆盖规则。
2. **Figure 4 固定窗并非完全同参数比较。** 功能群 PCA 保留 80% 方差，解剖 ROI 为 95%；Response 时间窗分别是 `[0,1)` 和 `[-0.5,0.5)`。图上的 bar、误差线、置换 p 值对应第一轮 5-fold；另存的 30 轮结果没有用于这些 bar。
3. **不同统计图的校正范围不同。** Figure 3 某些着色使用未校正 p；Figure 4 的一维时间簇和二维时间泛化簇使用不同簇统计量；Figure 5 的 Delay+Go 与 Response 分批校正。不能统一写成“均经全局 FDR/cluster correction”。
4. **名义时间与采样点时间不同。** RT 的 200 ms/20 ms 在 128 Hz 上实现为 26 点/3 点；实际步长 23.4375 ms。LDA 的横轴标的是滑窗终点；RT 横轴标窗中心。
5. **Figure 1 与部分下游结果依赖旧目录。** 当前工作区不是完全自包含的可重跑发布包。旧路径和当前解析到的结果路径已列入证据清单。

## 迁移时的最小交付

每次分析发布至少冻结：原始数据版本、事件定义、采样率、通道名单及排除原因、ROI 标签、NMF 输入矩阵及行列顺序、H/W 与标签覆盖记录、每个 fold 的 trial/item 列表、随机种子、完整超参数、置换单位、校正 family、结果文件、环境版本与源码指纹。图只读取这一份冻结结果，不临时重选电极或重写功能标签。

分支的具体步骤、公式、参数、图形聚合方法和可解释范围见各模块。复现现有图与改进新项目设计需要分开版本管理。
